# ЛР3 — L2-регуляризация и компромисс между скоростью и качеством решения

## 1. Цель эксперимента

Продолжить исследование L2-регуляризации из ЛР2 на **задаче Марковица с ограничениями**. Проверить, насколько добавление регуляризатора улучшает обусловленность, влияет на число итераций проецируемого градиентного спуска (projected GD), изменяет исходную целевую функцию и уводит оптимальный портфель от решения исходной задачи. Отдельно проверить допустимость портфелей и принадлежность решений заданным ε-окрестностям исходного оптимума.

## 2. Обозначения и финансовый смысл

| Обозначение | Смысл в задаче |
|---|---|
| `n` | Число активов в портфеле (`n = 12`) |
| `w ∈ R^n` | Вектор долей капитала, вложенных в активы |
| `A ∈ R^(n×n)` | Оценка ковариационной матрицы доходностей; в коде `oracle.A` |
| `b ∈ R^n` | Вектор оценок ожидаемых доходностей; в коде `oracle.b` |
| `λ` | Коэффициент при доходности в исходной модели (`λ = 1`) |
| `w_max` | Максимальная доля одного актива (`0.25`) |
| `r_min` | Минимально допустимая ожидаемая доходность |
| `α ≥ 0` | Коэффициент L2-регуляризации |
| `w*` | Эталонный оптимум исходной **ограниченной** задачи (`α = 0`) |
| `w_α` | Решение projected GD для регуляризованной задачи |
| `w*_α` | Эталонное решение регуляризованной ограниченной задачи, найденное SLSQP |
| `ε` | Допустимое отклонение от исходного оптимума по евклидовой норме |
| `Π_C` | Евклидова проекция в допустимое множество `C` |

## 3. Исходная constrained-постановка

Минимизируется исходная функция Марковица:

```text
f(w) = (1/2) · wᵀ A w − λ · bᵀ w,     λ = 1.
```

Допустимое множество:

```text
C = { w :  Σᵢ wᵢ = 1,
           0 ≤ wᵢ ≤ 0.25 для всех i,
           bᵀ w ≥ r_min }.
```

Экономический смысл ограничений:

- `Σᵢ wᵢ = 1`: весь капитал распределён между активами;
- `wᵢ ≥ 0`: короткие позиции запрещены;
- `wᵢ ≤ 0.25`: один актив не занимает более 25% портфеля (диверсификация);
- `bᵀw ≥ r_min`: ожидаемая доходность не должна быть ниже заданного уровня.

В данном **эксперименте регуляризации** ограничение `wᵀAw ≤ risk_max` **не включено**. Риск `wᵀAw` вычисляется как метрика и сохраняется в таблицу.

Для воспроизводимости значение `r_min` формируется по правилу:

```text
r_equal = bᵀ (1/n, …, 1/n)
r_max   = max {bᵀw : Σᵢwᵢ = 1, 0 ≤ wᵢ ≤ 0.25}
r_min   = r_equal + 0.25 · (r_max − r_equal).
```

Это делает порог доходности выше доходности равновесного портфеля, но не выше максимальной достижимой доходности при ограничении долей.

## 4. Регуляризация и её последствия

К исходной функции добавляется L2-штраф:

```text
F_α(w) = f(w) + (α/2) · ||w||₂².
```

Градиент и гессиан:

```text
∇F_α(w) = Aw − λb + αw
∇²F_α(w) = A + αI.
```

Для положительно определённой `A` число обусловленности гессиана:

```text
κ(α) = [λ_max(A) + α] / [λ_min(A) + α].
```

L2-регуляризация улучшает спектральную обусловленность, но **меняет оптимум задачи**: минимизация `F_α` не эквивалентна минимизации `f`. Поэтому нельзя оценивать качество только по `F_α(w_α)` и числу итераций. Нужно также проверять `f(w_α)`, разрыв `f(w_α) − f(w*)`, расстояние `||w_α − w*||₂` и нарушения ограничений.

## 5. Метод, начальная точка и проверка допустимости

Использован проецируемый градиентный спуск:

```text
η_α = 1 / (λ_max(A) + α)
w_(k+1) = Π_C [ w_k − η_α · ∇F_α(w_k) ].
```

Сначала рассматривается равновесная точка `(1/n, …, 1/n)`. Она проецируется на `C`; затем допустимость `w₀` проверяется через `oracle.is_feasible(w0, 1e-8)`.

Проекция выполняется в два этапа: сначала на симплекс с ограничениями долей `Σwᵢ = 1`, `0 ≤ wᵢ ≤ 0.25`, затем, если необходимо, численной минимизацией расстояния до точки с помощью `SLSQP` с учётом ограничения доходности. Полученная точка обязательно проверяется на допустимость.

Критерий остановки — норма отображения проецируемого градиента:

```text
g_P(w_k) = [w_k − Π_C(w_k − η_α ∇F_α(w_k))] / η_α
||g_P(w_k)||₂ ≤ 1e−8.
```

Это корректнее обычной нормы градиента `||∇F_α(w)||` для задачи с активными ограничениями. Максимум итераций — `3000`. Один и тот же допустимый `w₀` используется для всех `α`.

Эталонные решения `w*` и `w*_α` вычисляются численным методом `SLSQP` при тех же ограничениях. Расстояния до них являются сравнением с **численным эталоном**, а не доказательством точного аналитического оптимума.

## 6. Настройки воспроизводимого эксперимента

- Данные: синтетические данные существующего оракула `ConstrainedMarkowitzOracle` из проекта; **не рыночные котировки**.
- `n = 12` активов, `n_periods = 300`, `seed = 0`.
- `λ = 1`, `w_max = 0.25`.
- `α ∈ {0, 10⁻⁶, 10⁻⁵, 10⁻⁴, 3·10⁻⁴, 5·10⁻⁴, 10⁻³, 2·10⁻³}`.
- `ε ∈ {0.03, 0.10, 0.25}`.
- Сходимость: `||g_P||₂ ≤ 10⁻⁸`.
- Во всех сериях используется одинаковая модель, допустимая начальная точка и ограничения.

## 8. ε-окрестность исходного решения

Идею контроля изменения портфеля проверяем условием:

```text
||w_α − w*||₂ ≤ ε.
```

В текущей реализации **ε-условие проверяется после решения**, а не добавляется как ограничение в оптимизатор. Поэтому результаты показывают, какие из найденных портфелей попадают в заданную окрестность.

| ε | Подходящие коэффициенты α из исследованной сетки |
|---:|---|
| 0.03 | 0; 0.000001; 0.00001; 0.0001; 0.0003 |
| 0.10 | Все перечисленные выше, а также 0.0005 |
| 0.25 | Все исследованные α |

Например, при `ε = 0.10` коэффициент `α = 0.0005` даёт расстояние `0.067078`, а `α = 0.001` — уже `0.125073`, то есть выходит за выбранную окрестность. Это демонстрирует компромисс между силой регуляризации и сохранением исходного состава портфеля.

## 11. Главный вывод для защиты

L2-регуляризация улучшает обусловленность матрицы задачи Марковица с ограничениями, но не гарантирует ускорения проецируемого градиентного спуска. При увеличении `α` оптимальный портфель может заметно измениться, а значение исходной целевой функции — ухудшиться. В нашем эксперименте `κ` снизилось с `88.428` до `1.815`, но минимальное число итераций осталось у варианта без регуляризации (`7` итераций). При `α = 0.002` расстояние до исходного решения достигло `0.164447`. Поэтому выбор `α` нужно обосновывать сразу по нескольким метрикам: обусловленности, итерациям, значению исходной функции, расстоянию до исходного оптимума и допустимости решения.
